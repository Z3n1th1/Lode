# 密钥与配置泄露

## 找什么

- 硬编码：API key、DB 口令、JWT secret、云 AK/SK、私钥、对称密钥。
- 配置：`.env`、`config.*`、`settings.py`、CI 变量、容器 env、`docker-compose`。
- 前端产物：打包进 JS bundle 的 key/token/内部地址（前端可见 = 公开）。
- 日志与回显：异常栈、调试输出、打印的请求体/凭据。
- 版本库：被删但仍留在历史里的旧配置（`git log -p`）。

## 判定要点

1. **是否真是秘密**：占位符 / 示例值 / 已发送到前端的"公开 key"不算。
2. **是否可用**：有没有配套的 identify（如 AK 需配 SK），是否需要额外权限。
3. **影响面**：能读写什么、能扩权到什么程度。
4. **只验证存在性**：**不实际调用**真实凭据、不横向、不取数据；证据到"源码中出现"即可。

## 输出

```
位置     文件:行
类型     <密钥类型>
值       <脱敏，仅首尾各 4 字符>
影响     可访问 <什么>
建议     轮换 + 移入密钥管理 + 探针扫历史提交
```
