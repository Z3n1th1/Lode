# 越权

## 检查点
- 资源 id 可枚举？（自增 id、可预测 UUID、邮箱/手机号作为键）
- 只校验"登录"，不校验"归属"？→ 换一个对象 id 试试。
- 横向（同角色换用户）vs 纵向（低权限做高权限操作）。
- 隐藏端点：前端不显示但后端仍可调用（从 JS 里找）。

## 只读验证法
1. 用账号 A 的会话请求 A 的资源，记录基线。
2. 换成 B 的资源 id，**只发 GET**，比对响应差异（200/403/404、字段差异）。
3. 若返回他人数据 → 证据充分，记 finding（附两端请求响应）。

## 注意
- 不要用写操作验证越权（会改动他人数据）；GET 能证明就够。
- 403 vs 404 的差异本身就是信息泄露（存在性探测）。
